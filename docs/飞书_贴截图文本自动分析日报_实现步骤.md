# 飞书实现：贴截图/文本 → 自动分析 → 日报

> 目标：在飞书群内贴小红书评论截图或文字，由机器人自动分析并输出结构化结果，每天定时生成日报。  
> 本文档给出尽量简单的 MVP 步骤，先跑通流程，再迭代完善。

---

## 步骤 1：决定数据流 & 最小 MVP 形态

先不追求「一切自动」，先做到：

1. 你在飞书某个群里 **手动贴小红书评论截图** 或 **复制文字**
2. 一个飞书「机器人/应用」自动：
   - 把这段文字/图片转成结构化文本
   - 调用上面的 Agent Prompt 做分析
   - 在同一个群里回一条「结构化 JSON + 人类可读摘要」
3. 每天定时（比如 10:00）再用一个脚本/机器人：
   - 拉过去 24 小时内的所有分析结果
   - 汇总成「日报」，发到同一或另一个群

---

## 步骤 2：在飞书创建一个「自建应用 + 机器人」

1. 打开 **飞书开放平台** → **创建企业自建应用**
2. 开启权限：
   - 接收群聊消息（机器人）
   - 发送消息到群
3. 配置机器人 Webhook / 事件订阅（或直接用飞书提供的「机器人 + 云函数」模板）
4. 将机器人拉进你用来收集反馈的飞书群

**若希望尽量少写代码：** 可用 n8n / Make / Zapier（如支持飞书）对接「飞书机器人 → 自己的 LLM 服务」。

---

## 步骤 3：实现「消息 → 调用 LLM/Agent」

有两种策略，按自己熟悉的选：

### 方案 A：自建 Node/Python 服务

收到飞书机器人事件（群消息）时：

1. **过滤**：只处理 @ 机器人的消息，或以特定前缀开头（如 `【小红书】`）
2. **提取文本**：若是截图，先走 OCR（飞书自带 OCR 或其他服务）
3. **包装输入**：为每条反馈生成 `id`，包装成数组：
   ```json
   [
     {
       "id": "2026-03-15-001",
       "content": "用户原始评论文本/私信内容..."
     }
   ]
   ```
4. **调用 LLM**：
   - **System**：用《Agent 分析 Prompt 草稿》全文
   - **User**：传入上述 JSON 数组
5. **存储 & 回复**：
   - 把模型返回的 JSON 数组存进数据库（Airtable / Notion / Sheet / Supabase）
   - 在群里回一条简化摘要，例如：
     > 「识别到 1 条问题：P1 / 类型：behavior_mismatch + bug / 建议检查：api/gemini/proxy.ts 的 actionType 配额逻辑」

### 方案 B：飞书内置 LLM/Agent

1. 用飞书「智能机器人 / 智能问答」：
   - 将《Agent 分析 Prompt》作为「机器人配置」的基础
   - 将《Offerin 产品 & 技术架构说明》加入知识库
2. 配置：当用户 @ 机器人并附上反馈时，用该 Prompt 回答
3. 若飞书暂时不支持完全自定义 JSON 输出 + 定时调度：
   - 先只用它在群内自然语言回答（问题类型 + 优先级 + 建议）
   - MVP 跑顺后，再用外部服务做「结构化 JSON + 日报汇总」

---

## 步骤 4：实现「每日日报」

不管分析结果放在哪里（文件 / Sheet / DB），日报逻辑类似：

### 定时任务

用 crontab + Node 脚本，或 n8n Scheduled Trigger：

1. 从存储里查询：**过去 24 小时内的所有分析结果**
2. 按 `priority` 排序：先 P0，再 P1，再 P2
3. 生成飞书富文本消息，例如：

```
【Offerin 小红书反馈日报】2026-03-15

P0（1 条）
#1：模拟面试入口点击后提示「诊断次数用完」 
→ 可能是 actionType 混用 / 配额配置问题。
建议检查：services/geminiService.ts 的 createAIClient 调用 
+ api/gemini/proxy.ts 的 normalizedAction。

P1（2 条）
…

P2（若干条）
…
```

4. 通过飞书机器人 Webhook 把消息发到「产品问题日报」群

---

## 小结：MVP 检查清单

- [ ] 飞书自建应用 + 机器人拉进反馈群
- [ ] 消息触发：@ 机器人 或 前缀 `【小红书】`
- [ ] 文本/截图 → 结构化内容（必要时 OCR）
- [ ] 调用 LLM（System=Agent Prompt，User=反馈 JSON）
- [ ] 分析结果存库 + 群内回复摘要
- [ ] 定时任务：每日 10:00 汇总过去 24h → 发日报到指定群
